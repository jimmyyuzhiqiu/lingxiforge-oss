# Lingxi Forge 文创提示词模板（V1）

## 1) 核心结构
- 文化母题：来源、时代、器型、纹样
- 使用场景：冰箱贴、摆件、灯饰、文具、研学教具等
- 材质方向：树脂/PLA/尼龙/金属化
- 交付约束：小体量可打印、最小壁厚、可拆件、易后处理

## 2) 模板句式
请基于【文化母题】设计一款【产品类型】，强调【造型与纹样特征】；
材质倾向为【材质方向】；
要求满足【交付约束】；
风格为【写实/雕塑/现代简化】；
用于【馆店上新/品牌联名/教育传播】场景。

## 3) 负面约束
- 避免过薄结构与大面积悬垂
- 避免非流形与破面
- 避免过度复杂纹样导致细节不可打印

## 4) 评审口径
- 文化识别度是否明确
- 功能与结构是否匹配
- 是否具备可制造与可交付条件
